# Customer Shopping Behaviour – Data Analytics Project

This project analyzes customer shopping behavior using SQL, Python, Power BI, and a structured dataset. The goal is to uncover trends in purchasing patterns, customer segmentation, product performance, and revenue insights.

---

## 📂 Project Contents

- **Customer_shopping_behaviour.ipynb** — Jupyter Notebook containing exploratory data analysis (EDA)
- **Customer_shopping_behaviour_project_MySQL.sql** — SQL queries for data extraction, cleaning, and analysis
- **Customer Shopping Behaviour BI.pbix** — Interactive Power BI dashboard
- **customer_shopping_behavior.csv** — Dataset used in analysis
- **Customer Shopping Behavior Analysis.pdf** — Final analytical summary report

---

## 🎯 Project Objectives

- Understand customer purchasing behavior
- Identify high-value customer segments
- Analyze revenue distribution and product performance
- Build an interactive dashboard for business insights
- Perform EDA using Python and SQL

---

## 🛠 Tools & Technologies

- **Python (Jupyter Notebook)** — Data cleaning, visualization, EDA
- **MySQL** — Querying, transformation, and aggregation
- **Power BI** — Dashboards and KPI visuals
- **CSV Dataset** — Raw data for analysis

## 🚀 How to Use This Project

1. **SQL File**  
   Open `Customer_shopping_behaviour_project_MySQL.sql` in MySQL Workbench or any SQL environment and run queries.

2. **Power BI Dashboard**  
   Open `Customer Shopping Behaviour BI.pbix` in Power BI Desktop.

3. **Jupyter Notebook**  
   Run `Customer_shopping_behaviour.ipynb` in Jupyter Notebook/JupyterLab.

4. **Dataset**  
   Use `customer_shopping_behavior.csv` for additional analysis or modeling.
